# 📚 考研英语词库

一款基于 **SM-2 间隔重复算法** 的考研英语词汇学习 PWA 应用，帮助考生高效记忆、科学复习考研英语单词。

> 纯前端架构，无需后端服务器，所有数据存储在浏览器本地，支持离线使用。

---

## ✨ 功能介绍

### 🏠 首页仪表盘

- 展示今日学习概况：新学单词数、复习单词数、连续打卡天数
- 整体学习进度环形图，直观显示掌握百分比
- 按词频分级（高频 / 中频 / 低频）的进度条
- 快捷入口卡片，一键进入学习或复习
- 学习计划概览（每日新词数量、目标日期）
- 深色模式切换

### 📖 学习新词

- 以可翻转闪卡形式呈现新词，支持手势操作
- **正面**：单词、音标、词性、词频标签、词根标签、发音播放按钮
- **背面**：中文释义、英文释义、考研真题例句（含中文翻译和出处年份）、近义词、常用搭配
- 翻转后进行 **6 级自评打分**（0 = 完全忘记，5 = 完美记忆）
- 学习进度条实时跟踪当前批次进度
- 完成后展示本次学习准确率和逐词复习摘要
- 按词频优先级排序：高频词优先，其次中频，最后低频

### 🔄 间隔复习

- 自动筛选今日到期需复习的单词，按逾期时间排序
- 每次评分后，SM-2 算法自动计算下次复习时间间隔
- 完成后展示复习数量、准确率、已掌握单词数

### 🧠 SM-2 间隔重复算法

基于 SuperMemo 2 算法，针对考研备考场景深度定制：

| 评分 | 含义 | 复习策略 |
|------|------|----------|
| 0-2  | 未记住 / 模糊 | 学习阶段短间隔重复（1分钟 → 5分钟 → 15分钟 → 1小时 → 4小时） |
| 3-5  | 基本记住 / 清晰 | 复习阶段递增间隔（1天 → 3天 → 7天，之后按难度因子几何增长） |

- **难度因子动态调整**：初始值 2.5，最低 1.3，最高 3.5；连续 3 次以上高分获得额外加成
- **备考阶段感知**：冲刺阶段（考前 30 天）间隔缩短 30%，强化阶段（30-90 天）缩短 15%
- **单词状态流转**：新词 → 学习中 → 复习中 → 已掌握（连续 5 次评分 ≥ 4 自动标记为已掌握）
- **最大复习间隔**：180 天封顶

### 📚 词库浏览

- 全文搜索：支持按单词、释义、词根检索
- 多维筛选：按词频等级（高频 / 中频 / 低频）和学习状态（新词 / 学习中 / 已掌握）过滤
- 可展开的单词卡片，展示完整词条信息
- 每个单词和例句均支持音频播放

### 🌱 词根词缀

- 分标签页展示 **20 个常用词根** 和 **12 个词缀**（8 个前缀 + 4 个后缀）
- 每个词根/词缀包含：本身、含义、拉丁/希腊语源、详细说明和示例单词
- 可展开查看词库中相关的派生词，支持音频播放
- 通过构词法分析辅助记忆，举一反三

### 📊 学习统计

- 连续打卡天数统计（带动画火焰图标）
- 答题正确率
- 掌握进度环形图，按词频分级展示
- 近 14 天每日新词量和复习量柱状图
- **艾宾浩斯遗忘曲线**可视化（72 小时理论记忆保持率）
- 单词状态分布环形图（已掌握 / 学习中 / 新词）
- 学习小贴士
- **每日打卡分享**：生成格式化分享文案，支持 Web Share API 分享或一键复制到剪贴板

### 🔊 音频系统

- 约 387 个单词和例句的预生成 WAV 音频文件
- 通过 Python 脚本（`scripts/generate_audio.py`）调用 MiMo TTS API 批量生成
- **智能回退**：优先加载预生成音频，若不可用则自动使用浏览器 Web Speech API 朗读
- Service Worker 采用缓存优先策略，重复播放速度更快

### 📱 PWA 离线支持

- 支持添加到手机主屏幕，独立窗口运行
- Service Worker 三级缓存策略：
  - **音频文件**：缓存优先，快速回放
  - **页面导航**：网络优先，缓存兜底
  - **静态资源**：缓存优先，网络兜底
- 首次加载后可完全离线使用

### 💾 本地数据持久化

基于 IndexedDB 实现四大数据存储：

| 存储 | 用途 |
|------|------|
| `progress` | 每个单词的学习进度、评分历史、下次复习时间 |
| `dailyStats` | 每日学习统计（新词数、复习数、正确率） |
| `studyPlan` | 用户学习计划配置 |
| `learningCurve` | 历史学习曲线数据点 |

- 连续打卡自动计算：检测昨日统计维持或重置打卡天数

```
│   ├── dictionary/page.tsx      # 词库浏览页

│   ├── FlashCard.tsx            # 可翻转闪卡（含 6 级自评）
│   ├── ProgressRing.tsx         # SVG 环形进度指示器
│   ├── StatsChart.tsx           # Chart.js 图表封装
│   └── WordCard.tsx             # 可展开单词卡片
├── lib/                         # 核心逻辑
│   ├── types.ts                 # TypeScript 类型定义
│   ├── words.ts                 # 主词库（75 个高频词 + 子模块聚合）
│   ├── words_*.ts               # 分频词库文件（高频 / 中频 / 低频）
│   ├── sm2.ts                   # SM-2 间隔重复算法实现
│   ├── db.ts                    # IndexedDB 数据库层
│   ├── context.tsx              # React Context 全局状态管理
│   ├── utils.ts                 # 工具函数
│   └── roots.ts                 # 词根词缀数据库
├── public/                      # 静态资源
│   ├── manifest.json            # PWA 清单文件
│   ├── sw.js                    # Service Worker
│   └── audio/                   # 预生成音频文件（单词 + 例句）
└── scripts/
    └── generate_audio.py        # TTS 音频批量生成脚本
```

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm / yarn / pnpm / bun

### 安装与运行

```bash
# 克隆项目
git clone <repository-url>
cd kaoyan-english

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

打开浏览器访问 [http://localhost:3000](http://localhost:3000) 即可使用。

### 构建部署

```bash
# 生产构建
npm run build

# 启动生产服务
npm start
```

### 音频生成（可选）

如需重新生成音频文件：

```bash
cd scripts
pip install -r requirements.txt  # 安装 Python 依赖
python generate_audio.py
```
